# 抖音直播在线人数

在自己的电脑上盯住若干抖音直播间，查看当前在线人数。添加直播间链接、房间号或抖音号，页面大约每 10 秒自动刷新。名单保存在本机，重启后还在。

这不是抖音官方产品，也不使用官方开放平台的密钥。程序只读取未登录也能看到的公开直播间数据。

## 环境

- Python 3.10 或更高版本
- 不需要安装第三方包，标准库就够了
- 不需要抖音账号，仓库里也没有任何密钥

## Windows 上运行

1. 安装 Python。到 [python.org/downloads/windows](https://www.python.org/downloads/windows/) 下载，安装时勾选 **Add python.exe to PATH**。
2. 打开「命令提示符」或 PowerShell，进入本目录：

   ```bat
   cd 你解压或克隆到的目录
   py -3 server.py
   ```

   如果提示没有 `py`，改用：

   ```bat
   python server.py
   ```

3. 浏览器打开 [http://127.0.0.1:8741](http://127.0.0.1:8741)。
4. 停止服务：在那个窗口按 `Ctrl+C`。

第一次运行时，Windows 防火墙如果询问，选择允许专用网络访问即可。默认只监听本机 `127.0.0.1`，局域网里的其他设备连不上。

想换端口或把刷新放慢：

```bat
py -3 server.py --port 8741 --interval 15
```

`--interval` 只能设在 8 到 120 秒之间，避免把请求打得太密。

## macOS 或 Linux

```bash
python3 server.py
```

然后打开 [http://127.0.0.1:8741](http://127.0.0.1:8741)。

## 怎么用

1. 在输入框里可以：
   - 输入主播昵称（含中文或其他非英文数字字符），点「查找」。程序会在刚拉到的公开热门直播里按昵称包含关系列出房间。同名会都显示，点某一个的「添加」才会加入，不会猜一个加进去。
   - 或者粘贴下面任意一种，点「添加」：
     - 直播间链接，例如 `https://live.douyin.com/抖音号`
     - `v.douyin.com` 短链（需要能跳转到直播间）
     - 一场直播的房间号（通常是 16 位以上的纯数字）
     - 主播的抖音号（纯英文、数字、下划线、点号）。这类输入仍直接添加，不会先做昵称搜索。
2. 开播的房间显示昵称、头像、标题、**当前在线**和更新时间，并按在线人数从高到低排列。
3. 没开播显示「未开播」，不会让整个页面停掉。
4. 点左侧名单里的一场直播，右侧打开这场的详情，而不是只留一张小卡片。详情里能看到的只有公开接口里站得住的数字：本场新增关注、开播时长、点赞数量，以及本机刷新记下来的在线人数和其中的峰值。今日新增粉丝和按时间段的礼物数公开接口拿不到，详情里会写明原因，不会补一个 0。
5. 点「移出」从名单删除。名单写在 `data/watchlist.json`。
6. 「热播推荐」会拉一批当前公开信息流里正在直播的房间，方便点一下加入。这个列表不是完整榜单；拉不到时，手动添加仍然可用。
7. 同一次打开期间，开播房间会在详情里留下本机采样的在线人数。关掉程序后这段走势清空，名单还在。

最多同时监测 20 个直播间。

个人主页链接（`www.douyin.com/user/...`）不能直接用，请改成直播间链接或抖音号。

## 先确认网络

不打开页面，也可以先问一次抖音公开热播列表：

```bat
py -3 server.py --check
```

能打出几个正在直播的昵称和在线人数，就说明这条链路是通的。失败时退出码为 1，程序不会编造数字。

## 数据从哪来

只使用浏览器不登录也能打开的公开数据：

| 用途 | 地址 |
| --- | --- |
| 用直播间路径或抖音号找到房间 | `https://live.douyin.com/<路径>` 页面里的公开状态 |
| 按房间号读在线人数、昵称、头像 | `https://webcast.amemv.com/webcast/room/reflow/info/` |
| 热播推荐 | `https://live.douyin.com/webcast/feed/` |
| 按昵称查找 | 同一条公开信息流里首页热门直播卡片（`source_key=web_homepage_hot_web_live_card`）。拉到一批正在直播的房间后，在本地按昵称筛选。不调用需要登录的 `/aweme/v1/web/live/search/` 或用户搜索。 |

请求会带普通浏览器的 User-Agent。访问直播网页时会收下站点下发的 `ttwid` cookie，这是打开直播页时浏览器也会拿到的公开 cookie，不是登录态。

页面上有时把人数写成「100+」。程序优先采用接口里的整数在线人数（`user_count`，或「在线观众」那一项）。只有拿不到整数时，才会显示带 `+` 的大约值。抖音有的房间公开展示的是「人看过」，那和「当前在线」不是同一个数，界面上的大号数字是当前在线。

`aid=6383`、`app_id=1128` 是网页端公开的客户端标识，不是密钥。

## 局限

- **非官方**。抖音随时可能改页面或接口，改了之后这里会失败。失败时卡片上会写明错误，并尽量留着上一次成功的结果。
- 可能和抖音的用户协议冲突。请只把它当作个人查看公开直播间人数的工具，不要用来采集、转卖或干扰平台。
- 访问太密会被限流。默认 10 秒一轮，房间之间还有短暂间隔。不要把间隔改到 8 秒以下。
- 热播推荐只是公开信息流里的一小批正在直播的房间，不是全站排行。
- 昵称查找也只覆盖这次拉到的热门直播（大约几十个，有缓存），不是全站用户搜索。没开播的人、以及正在直播但没出现在这批信息流里的人，都不会出现。找不到时请改用直播间链接或抖音号。纯英文或数字会被当成抖音号直接添加。同名不会自动选中。人数只来自房间数据里的整数。
- 详情里的「本场新增关注」是 `stats.follow_count`，「点赞数量」是房间上的 `like_count`（`stats.like_count` 恒为 0，不用），「直播时间」用 `start_time` 算到现在。「峰值在线人数」是本机采样到的最高整数在线人数；公开字段 `max_audience_cnt` 在未登录时一直是 0，不当成峰值。没有自然日新增粉丝，也没有可靠的礼物时间段：未登录时礼物字段即使在热门直播间也是 0，所以不显示成 0。在线人数走势只来自本机采样。
- 未开播时，发现「重新开播」最多大约要多等两三轮刷新，因为新的一场会换成新的房间号。
- 头像链接由抖音签发，过期后会重新随房间信息更新。头像只从抖音图片域名回源，不会代理任意网址。
- 短链如果最终没有落到直播间，会提示添加失败。
- 编写时曾在可访问抖音的网络上核对过公开房间：同一场直播的在线人数会随刷新变化，未开播的房间返回未开播，不存在的抖音号会提示找不到。如果你这边打不开抖音，`--check` 会失败，界面里也不会出现假人数。

```
server.py          本地网页服务
douyin.py          公开直播间查询
static/            页面

tests/test_parse.py  不联网的解析测试
```

```bash
python3 -m unittest tests.test_parse
```
